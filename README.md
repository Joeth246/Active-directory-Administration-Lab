##Active Directory Home Lab – Windows Server 2022
Project Overview

This project demonstrates the setup and configuration of an Active Directory environment using Windows Server 2022 in a virtual machine. The goal was to gain hands-on experience with Windows Server administration, domain management, user account provisioning, Group Policy, and basic IT support tasks.

Throughout this lab, I configured a Windows Server 2022 virtual machine as a Domain Controller and practiced managing domain users, Organizational Units, security groups, and password resets.

Tools and Technologies
Windows Server 2022
Active Directory Domain Services (AD DS)
Virtual Machine (VM)
Server Manager
Active Directory Users and Computers (ADUC)
Group Policy Management Console (GPMC)

Lab Walkthrough
1. Downloading Windows Server 2022

Obtained the Windows Server 2022 installation media to prepare the environment for the Active Directory lab.

2. Installing Windows Server 2022 as a Virtual Machine

Created a virtual machine using Oracle Virtual box and installed Windows Server 2022 to establish the foundation for the lab environment.

3. Configuring the Server as a Domain Controller

Installed Active Directory Domain Services (AD DS) and promoted the Windows Server machine to a Domain Controller, establishing a domain environment for centralized identity and access management.

4. Creating Domain Users

Created domain user accounts in Active Directory to simulate a real-world organizational environment. This provided practical experience with account creation, user properties, and centralized user management.

5. Organizational Units and Groups

Created Organizational Units (OUs) to organize domain objects and security groups to simplify user organization and access management. This demonstrated how Active Directory can be structured to reflect departments and teams within an organization.

6. Group Policy Objects

Worked with Group Policy Objects (GPOs) to understand how administrators centrally manage user and computer settings across a Windows domain. Explored creating, configuring, and linking policies to Organizational Units.

7. Resetting Active Directory Passwords

Practiced resetting domain user passwords through Active Directory Users and Computers, simulating a common Help Desk and IT Support task. This provided experience with user account management and basic authentication troubleshooting.

Key Takeaways

Through this project, I gained hands-on experience with Windows Server 2022 administration, Active Directory configuration, Domain Controller management, user and group administration, Organizational Units, Group Policy, and password resets.

This lab strengthened my understanding of centralized identity management and common administrative tasks performed in IT Support, Help Desk, and System Administrator roles.

Conclusion

This project provided practical experience building and managing an Active Directory environment using Windows Server 2022. It helped develop foundational skills in Windows domain administration, user account management, and Group Policy configuration.
